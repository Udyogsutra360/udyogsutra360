# Udyog Sutra 360 One-Page Website

## Open the website

Open `dist/index.html` in a browser. No installation or build command is required.

## Files

- `dist/index.html` - page structure and Marathi-first content
- `dist/styles.css` - responsive brand design and animations
- `dist/script.js` - language switch, scroll effects, counters, parallax, tilt, navigation and form feedback
- `dist/assets/` - optimized Udyog Sutra 360 logo, favicon and campaign image
- `WEBSITE_PROMPT.md` - reusable prompt for regenerating or extending the website
- `brand-reference/` - supplied brand-guideline PDF

## Important notes

- Pricing, portfolio projects and testimonials are sample data and should be replaced before publishing.
- The contact form is a front-end demonstration. Connect it to email, WhatsApp, a CRM or a backend endpoint before going live.
- The default language is Marathi. A visitor's language choice is saved in the browser.
- The website uses Google Fonts when internet access is available and falls back to system fonts when offline.
