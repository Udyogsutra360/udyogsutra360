MAHARASHTRA PULSE - STATIC HTML PREVIEW

HOW TO VIEW:
1. Extract this ZIP.
2. Open the extracted folder.
3. Double-click index.html.
4. It opens directly in Chrome/Edge. No WordPress, XAMPP, npm or server is required.

This package is a static preview for quickly checking the design locally.
It does NOT include the WordPress admin/login or database functionality.
For customer daily news publishing, use the separate WordPress theme package.
